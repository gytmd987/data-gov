인사팀 문서 질의응답 시스템 구축 보고

한 줄 요약 — 인사팀 문서를 한곳에 모아두고, 사람에게 묻듯이 질문하면 답과 근거 문서를 바로 알려주는 사내 전용 시스템을 만들었습니다. 회사 서버 안에서만 돌아가므로 외부로 나가는 정보는 없습니다.

1. 어떤 불편을 해결하려 했나

  • 규정·지침·양식이 개인 PC와 공유 드라이브에 흩어져 있어, 어느 게 최신본인지 확인하기 어려웠습니다.
  • 같은 질문이 인사팀에 반복해서 들어오고, 답변하는 사람마다 참고한 문서가 달라 답이 조금씩 달랐습니다.
  • 급여·인사 정보처럼 민감한 내용이 많아 외부 서비스(ChatGPT 등)는 쓸 수 없었습니다.

2. 무엇을 만들었나

세 가지를 하나로 묶은 사내 웹사이트입니다. 직원은 브라우저로 접속해서 바로 쓸 수 있습니다.

화면하는 일
질문하기궁금한 걸 문장으로 물어보면 답변 + 근거가 된 문서를 함께 보여줍니다.
문서 관리문서를 올리고, 부서별 폴더로 정리하고, 찾아보고, 최신본으로 교체합니다.
조직·사용자 관리조직도와 구성원을 등록합니다. 이 조직도가 그대로 폴더 구조이자 열람 권한이 됩니다.

3. 어떻게 쓰나 — 세 가지 장면

장면 1. 궁금한 걸 물어본다

"육아휴직 신청은 며칠 전까지 내야 하나요?" 처럼 평소 말투로 물어보면, 시스템이 사내 문서에서 관련 내용을 찾아 읽고 답변을 만들어 줍니다.

  • 답변 아래에 어떤 문서의 어느 부분을 근거로 했는지 함께 표시됩니다. 원문 확인이 바로 가능합니다.
  • 관련 문서를 못 찾으면 지어내지 않고 "확인할 수 없습니다"라고 답합니다.
  • 답변이 틀렸으면 "틀렸어요"를 눌러 알려줄 수 있고, 이 기록이 개선에 쓰입니다.
  • 명단·급여 같은 엑셀 표에 대한 질문(예: "○○팀 인원이 몇 명이야?")은 실제로 계산해서 답합니다.

장면 2. 문서를 올린다

파일을 끌어다 놓으면 시스템이 문서를 읽고 정리 항목을 미리 채워 줍니다. 문서 종류, 제목, 요약, 핵심 키워드, 작성일·유효기간, 관련 부서 등입니다.

  • 올린 사람이 채워진 내용을 확인·수정한 뒤 "등록 확정"을 누르면 그때부터 검색에 나옵니다. (사람이 한 번 검토하는 단계를 일부러 넣었습니다.)
  • 어느 부서 폴더에 넣을지 고르기만 하면 저장 위치·작성부서·열람 권한이 한 번에 정해집니다.
  • 이미 같은 문서가 있으면 알려주고, "이게 새 버전이에요"라고 지정하면 옛 문서는 자동으로 검색에서 빠집니다.
  • 여러 파일을 한 번에 올릴 수 있고, 두 번째 파일부터는 앞에서 입력한 설정을 그대로 이어받습니다.

장면 3. 문서를 관리한다

  • 화면이 왼쪽 부서 폴더 / 가운데 문서 목록 / 오른쪽 상세 정보 세 칸으로 나뉘어 있어 클릭 한 번에 내용을 확인합니다.
  • 문서 상태는 유효 / 만료 / 보관 세 가지입니다. 만료된 문서와 옛 버전은 검색 결과에 뜨지 않습니다.
  • 여러 문서를 한 번에 삭제하거나, 다른 부서 폴더로 옮길 수 있습니다.

4. 정보 보안 — 볼 수 있는 사람만 봅니다

문서를 올릴 때 고른 부서가 곧 열람 범위입니다. 별도로 권한을 설정할 필요가 없습니다.

  • 그 부서와 하위 조직의 구성원 전원, 그리고 상위 부서장이 볼 수 있습니다.
  • 부서를 고르지 않으면 팀 전체에게 공개됩니다.
  • 권한이 없는 문서는 검색 결과에도, 답변의 근거에도 아예 나타나지 않습니다. 화면에서만 가려지는 방식이 아닙니다.
  • 문서 삭제와 타 부서 문서 수정은 부서장 승인을 거칩니다.
  • 누가 무엇을 검색하고 올렸는지 기록이 남습니다.

5. 믿을 수 있게 만든 장치

걱정되는 점대응
AI가 그럴듯하게 지어내면?사내 문서에서 찾은 내용만으로 답하고, 근거 문서를 반드시 함께 표시합니다. 근거가 없으면 모른다고 답합니다.
옛날 문서로 답하면?만료·구버전 문서는 검색 대상에서 자동 제외됩니다.
권한 없는 사람이 볼까?권한 없는 문서가 답변에 인용되면 테스트가 실패하도록 만들어 두고 매번 자동 점검합니다.
정리가 엉망인 문서가 들어오면?요약·키워드 같은 필수 항목이 비면 등록 자체가 차단됩니다.
외부로 정보가 나가나?회사 서버 안에서만 동작합니다. 외부 인터넷 연결이 필요 없습니다.

이와 별개로 자동 점검 테스트 144건을 만들어, 코드를 고칠 때마다 기존 기능이 망가지지 않았는지 자동으로 확인합니다.
